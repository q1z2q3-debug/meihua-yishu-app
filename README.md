# 梅花易数 · 全息占（Meihua Yishu · Holographic Divination）

单机离线的梅花易数全息排盘应用：时间起卦 / 铜钱摇卦 / 全息排盘 / 三元九维（洛书九宫 × 三态）全息观照 / 五段断语合成，以及 64 卦知识库与家宅调理建议。

- 形态：单文件 HTML（可直接浏览器打开）+ 安卓 APK（WebView 内置同一 HTML，无 Gradle 命令链构建）
- 版本：v2.0.0
- 定位：以「三元九维 19683 认知状态空间」（洛书九宫 × 每宫三态，3⁹=19683）为认知观照层，与梅花易数卦象相参的自我认知观测工具

## 功能

- **两种起卦**：时间起卦（农历年支/月/日/时辰，可手动修改）、铜钱摇卦（虚拟三枚六掷）
- **全息排盘**：本卦/变卦/互卦/错卦/综卦五卦齐观、体用生克、五行旺衰、世应之位、应期之断
- **三元九维 · 全息状态**（第五 Tab）：v2.0.0 全新重写——
  三元 = 体·用·变（27 格局）；九宫 = 洛书九宫 × 每宫三态（-1/0/+1），起卦先天数·排盘后天九宫；
  输出九宫状态码与三进制编号（0~19682，坎一最高位，中心态 9841）；
  四象回归伏羲四象（体用阴阳而定）、河图五行旺衰量化、偏移 = 宫气凝聚度
- **五段断语合成**（v2.0.0）：前四段延续体用基准 × 27 格局 × 四象相位时机 × 偏移把握，
  第五段为文王镜像卦短断（非覆即变对偶，如革之鼎·同人），排盘联动段与三元九维页合参卡双处展示；
  模板措辞本地合成（`sanReadingShort` / `sanReadingFull` / `mirrorShort`），无网络请求
- **卦象 · 家宅调理建议**：按本卦五行与动爻方位，推送九宫方位的宜储之酒、宜挂字画、主色、中国结、佐饰建议与禁忌（后天八卦九宫 × 五行双向索引）
- **卦辞爻辞详解**（原文 + 白话）、现代场景解读（事业/感情/财运/身心安康/出行）
- **知识库**：64 卦详解（卦辞/爻辞/白话启发/世应归属）、起卦入门、梅花易数经典原文
- **水墨国风**：留白、水墨渐变、行楷标题、首页水墨源流序言、洛书九宫盘可视化，延续「袖里乾坤」风格

## 快速使用

1. **直接使用**：浏览器打开 `meihua-yishu-app.html`（数据、算法、界面、插画全内联，无任何外部依赖）。
2. **安卓安装**：安装 `meihua-yishu-app-android14.apk`（包名 `com.meihuayishu.app`，minSdk 21 → Android 5.0+，targetSdk 34；首次安装需允许「未知来源应用」）。
3. **源码构建单文件 HTML**：

   ```bash
   cd src && node merge-data.mjs && node build.mjs
   ```

4. **构建 APK**：见 `apk-build/build.sh`（无 Gradle，用 AAPT2/D8/APKSIGNER/ZIPALIGN/ECJ 命令链）。需要 Android 构建工具链，通过环境变量指定：

   ```bash
   export ANDROID_TOOLS=/path/to/toolchain   # 内含 android-14/ android-34/ jdk/ 目录
   export MEIHUA_KS_PASS='your-keystore-pass' # 签名口令；密钥不存在时自动生成
   cd apk-build && ./build.sh
   ```

   注：仓库不包含签名密钥（`apk-build/keys/` 在 .gitignore 中），首次构建会自动生成自用调试密钥。

## 体系来源与声明

- 「三元九维 · 19683 认知状态空间」体系引自《认知生命体》（v8）研究文档，经整理适配后与梅花易数卦象相参。
- 本应用为单机离线版：无网络请求、不上传任何信息，全部数据与算法内联（仅用浏览器本地存储持久化）。
- 占卜与断语内容供文化研习与自我观照参考，不作为现实决策依据。

## 版本与发布

本项目采用「代码标签 + Release 归档」的版本管理机制：

- 每次功能迭代完成后，在 `main` 分支打语义化版本标签 `vX.Y.Z`（如 `v2.0.0`），并创建对应 GitHub Release；
