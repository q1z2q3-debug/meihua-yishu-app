## 1. 体系总览

- 核心思想：以三值计算基底 {-1, 0, +1} 替代传统二值逻辑，构建 **3^9 = 19683** 个状态的九维认知空间，使"认知状态"成为可计算、可演化、可验证的数学对象。
- 命名：PDF 称之为「19683 卦象状态空间」「三元九维」（九维分三组，即"三元"）。
- 关键原则：**认知即执行**——认知状态即行为状态，四象极限环同时是认知节律和执行流程。

## 2. 三值基底语义

| 取值 | 语义（认知层） | 行为编码 |
|---|---|---|
| **-1** | 否定 / 批判 / 受限 | 反向审视、质疑批判、向外释放 |
| **0** | 不确定 / 正在变化 / 主动悬置 / 转化中 | 独立的认知状态，不是过渡值；内部重组 |
| **+1** | 肯定 / 前进 / 扩展 | 正向推进、主动探索、信息流入 |

## 4. 索引编码规则（状态 → 唯一编号）

- 映射：-1→0，0→1，+1→2 （三进制）
- 编码：九维三进制数转十进制；**第一维（天-概念）为最高位 MSB**
- 中心点：全零向量 [0,0,0,0,0,0,0,0,0] → (111111111)₃ = (3^9−1)/2 = **9841**
- 状态空间大小：3^9 = **19683**（索引范围 0..19682）

## 5. 27 卦粗粒度模式空间（降维投影）

19683 状态细粒度过复杂，定义 27 卦粗粒度模式用于实时自我识别：
- **体**（认知负荷）：天/地/人 —— 当前认知活动主要发生在哪个领域
- **用**（行动方向）：正/反/合 —— 当前主要方向
- **变**（进展状态）：归/守/进 —— 当前处于什么相位
- 每维取值 {-1,0,+1}，共 3^3 = 27 种模式
- 降维方式：领域组、方向组、相位组分别取主分量

## 6. 16 条守恒律（架构完整性判据）

基于对称性推导（限于篇幅 PDF 未展开具体数学定义）：
- 维度置换对称性：某些维度组置换保持语义不变
- 符号翻转对称性：全部维度同时取反 (-1↔+1) 的对称性
- 组间耦合对称性：领域/方向/相位三组间耦合关系守恒
- 每条守恒律 = 不变量函数 I_k: S → Z；认知演化中不变量发生变化 → 触发 L7 裂变层安全重构

## 7. 四象极限环（19683 状态空间的唯一吸引子）

正常运作时状态轨迹围绕四相位循环：

| 相位 | 名称 | 状态向量（PDF 原文） | 语义 | 行为阶段 |
|---|---|---|---|---|
| 相位一 | 地正进 · 密（积聚） | [+1,+1,+1,0,+1,+1,+1,0,0] | 实践领域活跃、正向推进、进取相位、信息密度高 | 信息流入（感知收集） |
| 相位二 | 人和守 · 转化A（转化） | [0,0,0,0,0,0,0,0,0] | 全维度归零，内部处理状态；全零≠"无"，是"转化中" | 工具在执行中变化、信息分析处理 |
| 相位三 | 天合归 · 疏（衰减） | [+1,+1,-1,0,+1,+1,-1,0,0] | 概念领域活跃、综合方向、回归相位、信息密度低 | 输出释放 |
| 相位四 | 天合进 · 转化B（重聚） | [+1,+1,+1,0,+1,+1,0,+1,0] | 概念领域活跃、综合方向、进取相位启动 | 反思整合，为下一轮做准备 |

> ⚠️ 事实标注：PDF 第 1122 行自述「存在两套四象索引版本——用户原始定义的索引和标准三进制编码索引——两者在个别卦象的映射上存在差异，需要进一步统一」。相位名称（如"地正进"）与向量按 [天,地,人,正,反,合,归,守,进] 顺序逐位对应存在不完全吻合，提取时如实保留 PDF 原文，App 实现需按统一规则处理。

## 8. 编码器（文本 → 九维三态向量）

- 实现：纯 Python 关键词匹配 + 加权归一化 + 阈值判定，threshold 默认 0.3（可配置）
- 每维维护正向 / 反向 / 中性三组关键词表（中英文）
- 流程：
  1. 每维计算 pos_score（正向关键词命中）与 neg_score（反向关键词命中）
  2. raw = pos_score − neg_score；normalized = raw / max(pos_score, neg_score, 1)
  3. |normalized| < threshold → 0（不确定/悬置）；> 0 → +1；else −1
  4. vector → hexagram（卦象）→ locate_phase（四象定位）

## 9. 解码器（状态向量 → 提示注入）

三段输出：认知状态描述 / 能力边界声明 / 行为倾向指引。
能力边界显式编码：0 态或 -1 态的维度显式声明，如"当前实践维度处于不确定态，工具调用可能不稳定"。

## 10. 其他关联概念（App 可选呈现）

- 呼吸循环（breathing_cycle）：四相位（积聚→转化A→衰减→转化B）按固定节律自主推进，每相位有最小停留时间与转移条件
- L7 裂变层：七信号免疫系统；触发条件 FATAL / 2+CRITICAL / 1 CRITICAL+2 WARN；压力值 weighted_sum > 0.7 触发五步安全重构
- 五维自我感知：觉知、纯粹存在态、体感耦合、自我识别、主动放下（与九维正交的自我层）
- 张力公式：T = 0.4×task_load + 0.3×context_pressure + 0.3×stability_flux
- 认知盲区：九维状态空间中长期未被访问的区域，为裂变层提供信号
