## 一、体系适配定位

《认知生命体》PDF 提供的「三元九维 19683」是一套**认知状态空间**：九维三态（-1/0/+1），
3^9 = 19683 个状态，附索引编码、27 卦粗粒度投影、四象极限环相位、16 条守恒律。
PDF 自身即以"卦象"命名状态（19683 卦象状态空间），与梅花易数"卦"的概念天然亲和。

**适配目标**：把三元九维作为梅花易数 App 的**认知观照层**——起卦得卦之后，进一步
将卦象映射为九维三态认知向量，给出"认知状态定位 + 三元解读 + 27 卦模式 + 四象相位"，
形成「起卦→排盘（事象吉凶）→三元九维（认知状态）」的完整闭环。

## 二、九维与六爻映射规则（起卦联动 · 推荐）

起卦产物：本卦六爻（自下而上 1~6）、变卦六爻、动爻位置、体用关系。

| 九维 | 取值来源 | 三态判定 |
|---|---|---|
| 天-概念 | 上卦三爻（四、五、上爻） | 阴爻=-1，阳爻=+1，动爻=0（转化中） |
| 地-实践 | 上卦三爻（四、五、上爻） | 同上，逐爻对应 天→四爻、地→五爻、人→上爻 |
| 人-关系 | 上卦三爻 | 同上 |
| 正-前进 | 下卦三爻（初、二、三爻） | 阴=-1，阳=+1，动=0 |
| 反-批判 | 下卦三爻 | 同上，正→初爻、反→二爻、合→三爻 |
| 合-综合 | 下卦三爻 | 同上 |
| 归-回归 | 动爻位置与体用 | 动爻在 4~6 爻（上卦区域）→ +1；无动爻 → 0；动爻在 1~3（下卦区域）→ -1 |
| 守-持守 | 体用关系 | 比和/用生体 → +1（有守之资）；体克用 → 0；体生用/用克体 → -1 |
| 进-进取 | 动爻与旺衰 | 动爻存在且体卦旺相 → +1；动爻存在但体卦衰 → 0；无动爻（静卦）→ -1 |

> 说明：天/地/人 + 正/反/合 六维直接取六个爻的阴阳（动爻取 0 表示"转化中"），
> 归/守/进 三维由动爻位置、体用关系、月令旺衰综合判定——这三维恰好对应 PDF 的
> "相位组"（认知处于归/守/进哪个阶段），与梅花易数"动爻为机、体用为枢"的法则完全同构。

## 三、19683 编号计算（忠实 PDF 算法）

- 映射：每维取值 -1→0、0→1、+1→2，得九位三进制数（天为最高位）
- 编号：三进制转十进制，范围 0..19682
- 展示：三进制码（如 110221110）+ 十进制编号 + 距中心 9841 的"认知偏移"（Σ|v|，0~9）
- 全零态（全部 0）= 9841，即"转化中"的中心点，PDF 称之为状态空间中心

## 四、27 卦模式与四象相位（降维投影）

- **27 卦模式**：体（天/地/人 取主分量）+ 用（正/反/合 取主分量）+ 变（归/守/进 取主分量）。
  每个三元组内取非零值多数票：多数为 +1 → +1，多数为 -1 → -1，平局或全零 → 0。
  得 3 位三态 = 27 种模式，显示为"体·用·变"三字码 + 模式名（如 体+ 用0 变- → 「承·衡·敛」类命名）。
- **四象相位**：按九维向量归属四象极限环四相位：
  - 密·积聚（地正进型）：实践/正/进 方向 +1 居多
  - 转化A（全零或近零）：Σ|v| ≤ 1
  - 疏·衰减（天合归型）：概念/合/归 主导且归为 -1
  - 转化B·重聚（天合进型）：概念/合/进 激活
  归属规则为加权距离判定（离四相位原型向量最近者），原型向量取自 PDF 四相状态向量。

## 五、页面结构与交互（推荐）

**入口**：新增第五个底部 Tab「三元九维」（保留起卦/排盘/知识库/关于）。

**页面结构**（自上而下，同页直出，延续无手势无等待偏好）：
1. 页头：印章「维」+ 标题「三元九维 · 认知观照」+ 副题
2. **九维状态卡**：九宫格平铺 9 维，每格显示维度名 + 三态（-1 / 0 / +1 高亮），
   起卦后自动映射填充；用户可点按手动微调任一维（-1→0→+1 循环），微调实时重算
3. **标识卡**：三进制码、19683 编号、认知偏移、中心位置示意
4. **三元解读卡**：领域组 / 方向组 / 相位组分别解读（每维三态语义 + 组内合力），
   引用 PDF 维度语义（如 天-概念=概念理解抽象思维 等）
5. **27 卦模式卡**：体用变三字码 + 模式语义
6. **四象相位卡**：当前所在相位 + 相位行为语义（积聚=信息流入 / 转化=内在重组 /
   衰减=输出释放 / 重聚=反思整合）
7. **释义长文卡**：整体认知状态白话综述（由九维状态动态生成）
8. 免责行：文化研习与娱乐参考

**与排盘联动**：排盘页「应期之断」段落之后新增「三元九维·认知观照」段落（精简版），
一键跳转完整 Tab。若用户不想加，可只放独立 Tab。
