梅花易数·全息占 - 安卓单文件 HTML 原型（v1.3.0）
=================================================

meihua-yishu-app.html 是自包含单文件原型（数据、算法、界面、插画全内联，无任何外部依赖），
可用手机浏览器/安卓 WebView 直接打开。

功能：
- 两种起卦：时间起卦（农历年支/月/日/时辰，可手动修改）、铜钱摇卦（虚拟三枚六掷）
- 全息排盘：本卦/变卦/互卦/错卦/综卦五卦齐观、体用生克、五行旺衰、世应之位、应期之断
- 三元九维·全息状态：独立第五 Tab，纳入「认知生命体」三元九维编码体系——
  起卦后随排盘自动联动，输出九维（-1/0/+1）状态码与三进制编号（0~19682），
  支持九维格点逐位微调（卦象归零/复原），兼容二十七模式（体·用·变）与四态相位（密/转化A/疏/转化B·重聚）
- 三段断语合成（v1.3.0 新增）：排盘联动段出短句版断语（体用基准×27 模式短句×相位时机），
  三元九维页「与本卦合参」卡出完整版断语（再合偏移把握共四段），观卦断语·骨神合参，
  模板措辞经逐条确认冻结；全部本地合成，无网络请求
- 卦象·家宅调理建议：按本卦五行与动爻方位，推送对应九宫方位的宜储之酒、宜挂字画、主色、
  中国结、佐饰建议与禁忌清单（后天八卦九宫 × 五行双向索引）
- 卦辞爻辞详解（原文 + 白话）、现代场景解读（事业/感情/财运/身心安康/出行）
- 知识库：64 卦详解（卦辞/爻辞/白话启发/世应归属）、起卦入门、梅花易数经典原文
- 水墨国风视觉：留白、水墨渐变、行楷标题、周易元素，延续袖里乾坤风格
- 底部多屏 Tab：起卦 / 排盘 / 三元九维 / 知识库 / 关于

说明：本文件为单机离线版，全部数据与算法内联，不上传任何信息，可直接浏览器打开使用；
打包 APK 时即以此文件作为 WebView 内置页面。
